# E70 3.0sd (M57TU2 TOP, п'єзофорсунки Bosch): чому можуть не працювати всі 6 форсунок одночасно

Спільна логіка: одночасна відмова всіх 6 майже ніколи не означає 6 зламаних форсунок — шукаємо те, що спільне для всіх.

## A. Блок двигуна (DDE) НЕ дає команду на впорскування (логіка)
1. **Імобілайзер (EWS) — немає дозволу від CAS** (розсинхронізація після розряду АКБ / просідань). Помилка не завжди пишеться. ⭐
2. **Немає синхронізації по циліндрах**: сигнал датчика розподільного вала (або колінвала) відсутній/неправдоподібний. У нас оберти видно → колінвал ок; розподільний вал — під питанням.
3. **Контур тиску в рейці неправдоподібний** (датчик/регулятор): DDE може блокувати впорскування навіть без помилки. У нас тиск росте до ~400–490 бар і падає після прокручування → виглядає реальним.
4. **Занизькі оберти прокручування / напруга** для дозволу пуску.
5. **Сигнал аварії (crash)** від блоку подушок → відсічення палива (малоймовірно: насос у баку працює).
6. Особливий стан DDE (перерване програмування, захисний режим) — малоймовірно.

## B. Команда є, але не доходить до форсунок (електрика)
7. **Спільний роз'єм / джгут форсунок** (біля колектора або на DDE), перетиснутий дріт під колектором. ⭐ (після зняття колектора)
8. **Маса двигуна / живлення DDE** (головне реле, запобіжники, силова маса двигуна): DDE «живий» для діагностики, але не може зарядити високу напругу для п'єзофорсунок, особливо при просіданні на прокручуванні. ⭐ (масу могли зачепити при ремонті)
9. **Пошкоджені кінцеві каскади (high-voltage) у DDE** від стрибка напруги (пусковий пристрій, від'єднання під навантаженням, 24 В, переплутана полярність). Зазвичай пишеться помилка «Injektor Bank / Endstufe», але не завжди.

## C. Команда доходить, але форсунки не відкриваються (гідравліка)
10. **Тиск у рейці < ~250 бар** → форсунки не відкриються. У нас ок.
11. **Зворотка п'єзофорсунок**: п'єзофорсункам Bosch потрібен певний тиск у лінії зворотки (клапан утримання тиску). Якщо трубки зворотки від'єднані/злетіли або клапан несправний → форсунки не працюють. ⭐ (перевірити, чи не зачепили при знятті колектора)
12. **Повітря в рейці/форсунках** після робіт → довше прокручування, прокачка.
13. **Неякісне паливо / вода / бензин у дизелі** → усі одночасно.

## Як розрізнити A/B від C
- **Осцилограф на роз'ємі форсунки під час прокручування** (п'єзо — високі напруги ~100+ В: щуп ×10, НЕ контрольна лампа).
  - імпульсів немає → A або B (EWS, синхронізація, живлення/маса DDE, джгут, каскади DDE)
  - імпульси є → C (зворотка, повітря, тиск, паливо)
- Без осцилографа: огляд зворотки + маси + EWS (FS_LESEN D_CAS).

## Пріоритет для цього авто
1. EWS (CAS FS_LESEN → синхронізація)
2. Маса двигуна / живлення DDE після ремонту
3. Зворотка форсунок (трубки, кліпси, клапан утримання тиску)
4. Спільний роз'єм джгута форсунок / перетиснутий джгут
5. Осцилограф на форсунці
