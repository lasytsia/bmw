# M57TU2 — вакуум і форсунки, перевірка форсунок

## Вакуум
- Форсунки (п'єзо Bosch) вакуумом НЕ керуються: тільки паливо під тиском + електрика від DDE.
- Вакуум (від вакуумного насоса) на M57TU2: актуатори турбін (2 клапани-перетворювачі), EGR, гальмівний підсилювач, клапан байпасу охолоджувача EGR.
- Розрідження в паливній системі = погано: підсмоктування повітря / забитий фільтр / не працює насос у баку → бульбашки в паливі, тиск у рейці не тримається.
- Зворотка п'єзо-форсунок має працювати з невеликим підпором; розрідження чи відкрите повітря там — неприпустимо.

## Перевірка форсунок (від простого)
1. FS_LESEN DDE: помилки форсунок / кінцевих каскадів / rail.
2. `abgleich_ima_lesen` — IMA-коди мають відповідати наклейкам на форсунках.
3. Живі дані на ХХ: корекції подачі по циліндрах (laufruhe / mengenkorrektur), норма приблизно ±2–3 mg; один циліндр сильно відхиляється → підозріла форсунка.
4. Тест зворотки (бутлі/шприци на зворотку кожної форсунки, ХХ 1–2 хв або прокручування): об'єми мають бути близькі; одна з набагато більшою зворотками — несправна.
5. Тиск у рейці ist/soll на прокручуванні і ХХ; падіння при відключенні форсунок по черзі.
6. Опір п'єзо-форсунки (роз'єм відключений, мультиметр на 2 МОм): порядку сотень кОм, головне — однаковий у всіх 6; 0 Ом / обрив — несправна. Без прямої подачі 12 В на п'єзо!
7. Стенд у сервісі — остаточна перевірка.
