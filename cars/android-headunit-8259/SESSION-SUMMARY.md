# Підсумок сесії: Android-магнітола 8259 (BMW E60 CCC)

Технічні деталі, версії, коди, формат `can_app.bin` і посилання дивись у `README.md` у цій самій папці.

## Хронологія чату
1. **Ідентифікація магнітоли.** Скріни: замовлення AliExpress (12.2021, 1569,39 zł), інструкція продавця з оновлення CAN, «Про пристрій», екран після оновлення CAN.
   - Платформа: AutoChips AC8257/8259, модель `825X_Pro`, MCU `TsBMW`. Насправді Android 9, хоч і показує «11».
   - Майже ідентичний блок розібрано тут: https://github.com/PanduruIonut/bmw-e90-android-headunit-825x
2. **Чи є прошивки.** Офіційного архіву немає. Схожі пакети є лише від користувачів на XDA (посилання в README). Сайт xdaforums.com закритий у мережевих налаштуваннях хмарної сесії, тож самі теми я не відкривав.
3. **Чи можна доопрацювати.** Найкраща основа — власний дамп через `adb root`, бо збірка, ймовірно, `eng`/`test-keys`. Можна змінити UI, build.prop, root через Magisk і застосунки. MCU та CAN — лише заміна на готові версії.
4. **Аналіз `can_app.bin` від власника** (SHA-256 `63acd3af…c2b7`):
   - Усередині `YX-BMW-2 V206`, а на магнітолі `YX-BMW-GD-2 V210`. **Не прошивати повторно.**
   - Не шифрований. Cortex-M (STM32F1-клас), застосунок з `0x08002800`.
   - Контрольна сума в заголовку = −(сума байтів тіла). Можна переписати кнопки iDrive, але лише на прошивці GD-2 V210.
5. **Довге завантаження з чорним екраном.**
   - Уточнення від власника: це Android, до 5 хвилин, лого BMW блимає **один раз**. Буває лише після повного перезапуску (наприклад, після перегріву). Зазвичай магнітола в режимі очікування й прокидається швидко.
   - **Висновок:** найімовірніше, НЕ пов'язано з оновленням CAN. Імовірна причина: гарячий процесор після перегріву скидає частоту, тому холодний старт дуже повільний. Також можливі заповнена пам'ять або багато автозапусків.

## Що зробити далі
- [ ] Перезавантажити магнітолу вручну, коли вона **холодна**, і заміряти час. ~1 хв означає, що винне тепло; 3–5 хв — що проблема в системі чи пам'яті.
- [ ] ADB по Wi‑Fi (Налаштування → Про пристрій → 7× «Номер збірки» → USB debugging; вимкнути бездротові CarPlay/AutoLink):
  ```
  adb connect <IP>:5555
  adb root
  adb shell getprop ro.build.type
  adb shell getprop ro.build.tags
  adb shell cat /sys/class/thermal/thermal_zone*/temp
  adb shell df -h /data
  adb shell dumpsys meminfo | head -40
  adb shell ls -l /dev/block/by-name/
  ```
- [ ] Перевірити, чи є ззаду на корпусі вентилятор і чи він працює. За потреби додати вентилятор на 12 В або забезпечити приплив повітря.
- [ ] Код 8878: сфотографувати всі екрани CAN / Other / ACC / Sleep і **нічого не змінювати**.
- [ ] Попросити в продавця `can_app.bin` саме для **YX-BMW-GD-2 V210** (і MCU для `TsBMW.211019`).
- [ ] Якщо `eng` + `adb root` працюють, зняти дамп розділів (команди в README).

## Чого НЕ робити
- Не прошивати `can_app.bin` з V206 / V201.
- Не вводити коди 9090, 9191, 0, 0128, 4, 5, 180, 1701.
- Не робити скидання до заводських, поки не зняті логи та дамп.
